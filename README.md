# AI 趣味群聊（ai_groupchat）v2.1.0

QQ 移动端风格的 AI 社交面板。在 v2.0「消息 / 好友 / 动态 / 设置」四 Tab 架构之上，
本版完成 **全量改造**：时区根因修复、表情包大尺寸拆分、楼中楼评论、离线待回复、
消息转发、好友分组与特别关心、聊天搜索、用户资料与发说说、草稿保留、懒加载、
大图左右切换等 15 项前端 + 9 项后端能力。

> **核心原则：单轮单次模型调用。** 所有新增社交能力（签名 / 心情 / 动态 / 动态评论 /
> 楼中楼回复 / 转发 / 离线补回复）**全部复用同一次 `llm_generate` 的返回结果**，
> 衍生逻辑一律走「数据库 + 概率判定」，零额外模型请求。

## v2.1 新增内容

### 一、时区偏差根因修复
- **根因**：SQLite `CURRENT_TIMESTAMP` 存的是 UTC，而 `time.localtime()` 读服务器本地时区；
  服务器时区与用户所在地不一致时（UTC vs 东八区差 8 小时），就会出现「显示 4 点、实际 12 点半」。
- **方案**：新增配置项 `timezone_offset`（默认 8 = 东八区，可在插件配置页改）；
  后端新增 `_local_now()` 统一封装偏移，`_now_desc()` / `_role_status()` 全部改用偏移后时间，
  保证注入提示词的时段与用户本地一致；**数据库仍保留 UTC 存储**，前端统一转本地时间展示，双端对齐。
- **前端**：废弃原来直接截取后端时间字符串的写法，所有 `created_at` 统一转 `Date` 对象后
  按浏览器本地时区格式化；消息时间、时间分隔条、动态时间、会话列表时间全部对齐。

### 二、用户动态 + 评论全链路（全程单次调用）
1. **发动态零调用**：新增 `POST /api/user_moment`，用户发说说直接落 `moments` 表
   （`role_key='user'`），全程不触发模型请求。
2. **提示词自动注入**：`build_sys_prompt()` 新增「用户近期动态」区块，自动带入用户最新
   2 条公开动态，角色回复时自然提及「刷到你动态」的效果，零额外成本。
3. **动态评论同次生成**：模型返回的 `moment` 字段支持可选 `comments` 数组（1~3 条其他角色评论），
   按 `moment_comment_chance`（默认 40%）采纳落库，不发额外请求。
4. **楼中楼回复（本轮修正口径）**：模型可返回 `moment_replies`（带 `moment_id` +
   可选 `reply_to_comment_id`），落 `moment_comments` 表并保留 `reply_to` 链，
   **在原动态的评论区里继续盖楼**——不是强行插一条聊天消息，也不要求角色在对话中刻意提及
   （提示词只写"有想说的话就发到评论区"，偶尔自然提一句即可）。
   下次构建提示词时自动带上「近期动态评论区（楼中楼）」区块供角色参考。

### 三、用户资料体系（昵称 + 头像）
- `plugin_cfg` 表新增 `user_nickname` / `user_avatar` 两个键值（默认昵称「我」，不新增表）。
- 新增 `GET|POST /api/user_profile`：改昵称（≤20 字）、上传头像（后端校验大小）。
- 消息入库仍保持 `who='user'` 不变，仅在返回前端时替换为自定义昵称，历史数据完全兼容。
- 设置页顶部新增「个人资料」区块：头像上传（canvas 压到 256px）+ 昵称输入，失焦自动保存；
  气泡、会话列表、动态与评论中的「我 / user」全部替换为自定义昵称，头像走「上传图 → 首字占位」降级。

### 四、表情包拆分：强制独立大气泡
- 入库前 `_expand_emoji_rows()`：一条消息若同时含 `emoji_name` 与 `content`，
  强制拆成两条独立消息（第一条纯表情、第二条纯文字）；连续多个表情各拆一个气泡。
- `messages` 新增 `is_big_emoji` 列（幂等迁移），纯表情消息标 1。
- 前端 `.big-emoji` 样式：取消气泡背景与边框、120~140px、单独成行、紧贴头像侧，完全对齐微信 / QQ。

### 五、红点计数兜底
- 后端 `list_conversations()`：未读数超过 99 直接返回 `unread=99` 并带 `unread_overflow=true`。
- 前端再做一层截断：≥100 固定显示「99+」，红点徽章固定宽度不撑坏布局。
- 进入会话时 `markRead` 传 `read_id=-1`，后端一次性把已读水位拉到本会话最大消息 id，
  避免逐次累加的误差；退出会话二次校验同步。

### 六、作息离线待回复机制
- 新增 `pending_reply` 表（幂等创建）。角色处于「睡觉中」等离线时段时，消息不立即调模型，
  以 `pending` 状态入表，前端插入灰色系统提示「对方当前离线，醒来后会回复你」，不显示输入中。
- 每次触发对话时先检查时段：进入在线时段则取出全部待回复消息**合并进本轮提示词一次性回复**，
  回复首句自动带「刚醒才看到消息」等语境；生成失败则 `rehold` 回 `pending`，下轮再试。
- 角色由「离线」转「在线」时，私聊会话补一条轻量系统提示「XX 上线了」。

### 七、消息转发
- 新增 `POST /api/forward_msg`：把一条消息转发到其它会话，复用 `quote` 字段存
  `FWD::转发自 XX(会话名)：原文` 标记，前端渲染「转发自 xxx」引用条，点击展开完整上下文。
- 模型 `replies` 新增可选 `forward_from` 字段，按 `forward_chance`（默认 8%）触发角色
  转发「和别人的私聊截图」并附 1~2 句上下文，内容完全由本轮生成，无额外调用。

### 八、好友分组与特别关心
- `plugin_cfg` 新增 `friend_groups` 键（JSON：分组名 + 角色 key 列表），
  配套 `GET|POST /api/friend_groups`，支持新增 / 重命名 / 删除 / 移动角色 / 折叠展开。
- `conv_state` 新增 `special_care` 字段；会话与好友列表返回标记，前端高亮 + 专属标识，
  特别关心来消息时 toast 样式强化。

### 九、聊天记录搜索
- 新增 `GET /api/search_msg?kw=&room_id=`：SQLite `LIKE` 模糊搜索（`%` `_` 已转义），
  返回消息列表 + 所属房间名 + 上下文片段，默认最近 20 条。
- 设置页「搜索聊天记录」入口：关键词 + 房间筛选，结果按时间倒序，点击跳转对应会话并高亮定位。

### 十、前端其余 6 项交互
- **气泡操作条右侧悬浮**：`position:absolute` 定位在气泡右侧外 8px，默认透明 + 右偏 10px；
  hover 淡入左滑、垂直居中，完全不占气泡内部空间、不再导致气泡高度跳动；
  移动端取消 hover，保留长按弹出底部菜单。
- **输入草稿本地保留**：`draft_<room_id>` 防抖写入 localStorage，切换 / 重开会话自动回填半句话。
- **消息懒加载**：默认只渲染最近 50 条，滚到顶部自动加载上一批 50 条，并以消息位置锚点保持阅读位置不跳。
- **大图查看器左右切换**：打开时收集当前会话全部图片索引，支持左右箭头与键盘 ← → 连续翻看。
- **私聊已读细化**：群聊隐藏「已读 / 已发送」，仅私聊保留；已读状态只标在**最后一条**用户消息上。
- **快捷回复短语**：设置里可配常用短句，输入框右侧一键填入（额外补充项）。

### 十一、本轮顺手修掉的两个真问题
- `get_conv_state()` 的 SELECT 漏了 `special_care` 列 → 特别关心标记永远读回 0，已补列。
- 本轮没有任何角色接话时，前端提前 `return` 把同批返回的**动态 / 楼中楼评论 / 签名变更**一起吞掉，
  现已改为照常落地并提示（`applySocial()` 返回是否产生社交变更）。

## 配置项（插件配置页）
| 配置 | 说明 | 默认 |
|---|---|---|
| `llm_provider` | 模型提供者 ID，留空用默认对话模型 | 空 |
| `vision_enabled` / `max_image_side` | 发图识图开关与压缩最长边 | on / 1280 |
| `auto_talk_max_rounds` | 自主对话服务端兜底轮数上限 | 20 |
| `mood_change_chance` | 角色更新签名 / 心情的概率（%） | 12 |
| `moment_chance` | 角色发动态说说的概率（%） | 6 |
| `moment_comment_chance` | 动态生成时采纳其他角色评论的概率（%） | 40 |
| `forward_chance` | 角色转发私聊截图的概率（%） | 8 |
| `timezone_offset` | 时区偏移（小时），8 = 东八区 | 8 |

## 数据存储
SQLite 单库，表：`rooms / roles / emojis / messages / reactions / room_summary / plugin_cfg /
profiles / moments / moment_likes / moment_comments / intimacy / conv_state / pending_reply`。
v2.1 变更（全部幂等迁移，老库升级不丢数据）：`messages` 新增 `is_big_emoji` 列、
`conv_state` 新增 `special_care` 列、新增 `pending_reply` 表、`plugin_cfg` 新增
`user_nickname / user_avatar / friend_groups` 键。
私聊房间以 `dm@@<群房间>@@<角色名>` 作为 room_id，上下文独立隔离。


## 部署
1. 停止 AstrBot 进程；
2. 删除 `data/plugins/ai_groupchat` 旧目录（**务必删净**，避免残留旧 `app.js` 缓存）；
3. 把本 `ai_groupchat` 目录放入 `data/plugins/`；
4. 完全重启 AstrBot，侧边栏重新进入插件页并 Ctrl+F5 强刷；
5. 首次启动自动完成幂等迁移，历史聊天记录不丢；
6. 服务器时区与本地不一致时，在插件配置里确认 `timezone_offset`（东八区填 8）。
